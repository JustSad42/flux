# Flux

Windows media player (Tauri 2 + TypeScript + mpv). Docs: [README.md](README.md). Renamed from "Player" 2026-11-20 (old data folder `local.player` is migrated).
Until 1.0 it was written on a server and built over `ssh winpc` ([pc-tools/README.md](pc-tools/README.md)); since 1.1 (2026-11-23) it is built and tested directly on the PC.

- Brief (user): player-first, NOT a library app. No posters, catalog, indexing or DB. Priority: fast open, reliable playback, folder queue.
- Pure logic with tests (`npm test`, tsx): `src/queue/match.ts` (names, `discover`), `queue.ts`, `src/media/subs.ts` (subtitle matching), `src/media/markers.ts` (intro/outro, chapter nav, resume). Change them test-first.
- UI modules (1.2.1 refactor): `main.ts` = player state and logic (playback, queue, timeline, subtitles, Whisper, clips, keys, start-up); `mpv.ts` = pipe (`send`, `ask`, replies); `overlay.ts` = holes in mpv's window, toast, pop-up menu; `settings.ts` = defaults, dialog fields, `migrate`; `util.ts` = small helpers. Rust: `lib.rs` (state, helpers `locked()`/`quiet()`, start-up) + `mpv.rs`, `media.rs`, `whisper.rs`, `clip.rs`, `system.rs`.
- If mpv dies, the pipe reader drops the pipe and child and emits "shutdown"; the page (`mpvGone`) starts mpv again and reloads the file at its saved position (gives up after 4 crashes in 2 min).
- Whisper jobs run in a scratch folder (`%TEMP%\flux-whisper-<pid>`) and only the finished .srt is copied next to the video, so no preset can overwrite an existing subtitle file. Stop kills whichever step is running (`Job.pid`).
- The native mpv window covers `#video`; anything drawn over the picture must be a `.float` element shown with `setFloat()`, which makes `syncRect()` cut a (rounded) hole in mpv's window under it. A transparent web view does NOT work (Windows clips the sibling video window: the desktop shows through). Floats must be opaque.
- Opened with a file, Rust starts mpv as the very first thing in `run()` (`pre_start`, before Tauri/WebView2 exist) using the saved `input.conf`, settings and resume position, drawing into a child of a hidden stand-in window; `adopt_early` in `setup()` reparents it into Flux's window (SetParent). First frame ≈0.3 s after launch. The page then `adopt()`s the file and holds mpv events until it has (`holding`).
- Tray: hiding the window does not tell WebView2, so `set_asleep` (system.rs) sets the controller invisible + memory target Low when closing to the tray, and back on `show_main`. Without it the start screen's animations rendered at ~160 fps while hidden (bursts of a whole core). Test copies can set `FLUX_TEST_WAKE_MS` to reopen the window by themselves (stands in for a tray click).
- The pipe reader passes at most 10 `time-pos` events/s to the page (mpv sends one per frame).
- Measured 2026-11-23 (release build, 1080p60 AV1): playing = flux 0.5% + page 0.5% + mpv 2.8% of one core; tray = 0% CPU, page ≈200 MB; launch → playing 0.34 s. Re-measure with the scratch `measure.ps1` approach (Get-Process CPU deltas + mpv log) before and after perf changes.
- User decisions (2026-11-23): controls float and auto-hide; hover preview instead of a filmstrip; Whisper auto-detect language; extras = clip export, Recycle Bin, frame step/slow-mo.
- Whisper on this PC: whisper.cpp CUDA build + ggml-large-v3-turbo hard-linked from LingoReel into `%LOCALAPPDATA%\local.flux\whisper` (needs the cudart/cublas DLLs too, else it silently runs on the CPU). whisper.cpp defaults to English: always pass `-l`.
- Test copies: `FLUX_DATA` + own `WEBVIEW2_USER_DATA_FOLDER` (see README Testing). Tell the user before a test window appears; capture with PrintWindow when the window is not in front.
- mpv keys go through `input.conf` → `script-message act <name>` → `act()`; the `KEYS` table feeds both mpv and the page. mpv's own media session is off (`--media-controls=no`); media keys are Rust global hotkeys → `media-key` event.
- mpv IPC is ONE pipe handle (mpv sends replies/events only to the client that asked), read by polling `PeekNamedPipe` so writes never block (3 ms while busy, 12 ms when idle). flux.lua throttles mouse messages to ~10/s (immediately when crossing the bottom zone).
- PowerShell gotcha when scripting edits: `R` is the alias of Invoke-History; never name a helper function `R`.
- Child processes started from the GUI must get `Stdio::null()` for stdin (no console to inherit) or mpv can hang.
- Interpretation of the brief: the queue shows the full sorted run with the playing file marked (so Previous works), not the playing file first.
- Public repo `JustSad42/flux`; `.\release.ps1 <version> "notes"` builds, signs and publishes (README → Release). Updater key `~\.tauri\flux.key` stays off the repo. `tools/` and `pc-tools/` (screenshots, logs, PC paths) are git-ignored and must never be published.
- `src-tauri/src/flux.lua` runs inside mpv: mouse height → `act mouse <0..1>` (bar stays up near the bottom), click vs drag (pan when zoomed), Ctrl+wheel zoom. mpv needs `--window-dragging=no`, or a held click starts mpv's own window drag and the script never sees the drag. `keypress` from the pipe arrives as a single "press" event, real clicks as down/up.
- One floating menu (`#menu`, `openMenu(anchor, items)`) serves speed, audio and clip modes.
- Decisions 2026-11-23 (1.2): offline translation skipped (no NLLB/Marian model on disk, user declined a download); updates from the public repo.
